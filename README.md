# YouTube Trend Explorer - AI Automation with Gemini

Este repositorio contiene el flujo de trabajo (workflow) de automatización desarrollado para el Proyecto de Aula de la Corporación Universitaria del Huila (CORHUILA) El sistema utiliza **n8n** y **Google Gemini AI** para realizar vigilancia tecnológica automatizada sobre tendencias en YouTube.

## Descripción del Proyecto
El proyecto resuelve la necesidad de analizar grandes volúmenes de datos de video de forma eficiente. Mediante el uso de una arquitectura "Low-Code", este sistema extrae metadatos de YouTube, procesa la información cualitativa a través de Inteligencia Artificial Generativa (Gemini) y entrega reportes estructurados sobre sentimientos, tópicos y resúmenes de contenido.

## Tecnologías Utilizadas
* **[n8n](https://n8n.io/):** Orquestador de la automatización.
* **[Google Gemini API](https://ai.google.dev/):** Modelo de lenguaje (LLM) para el análisis de contenido y sentimiento.
* **[YouTube Data API v3](https://developers.google.com/youtube/v3):** Extracción de metadatos y tendencias.
* **Google Sheets:** Almacenamiento y visualización de datos finales.

## Características
* 🔍 **Búsqueda Automatizada:** Encuentra videos tendencia basados en palabras clave específicas.
* 🤖 **Análisis Cualitativo:** Genera resúmenes automáticos de los videos mediante IA.
* 🎭 **Detección de Sentimiento:** Clasifica la percepción de la audiencia.
* 📊 **Reporte Estructurado:** Exportación directa a hojas de cálculo para toma de decisiones.
