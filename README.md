# YouTube Trend Explorer - AI Local Automation with Ollama

Este repositorio contiene el flujo de trabajo (workflow) de automatización desarrollado para el Proyecto de Aula de la Corporación Universitaria del Huila (CORHUILA). El sistema utiliza **n8n** y **Ollama** para realizar vigilancia tecnológica local y privada sobre tendencias en YouTube.

## Descripción del Proyecto
El proyecto resuelve la necesidad de analizar grandes volúmenes de datos de video sin depender de servicios de nube costosos. Mediante el uso de una arquitectura "Low-Code" y Modelos de Lenguaje Locales (LLM), este sistema extrae metadatos de YouTube y procesa la información cualitativa utilizando Ollama. Esto permite generar resúmenes, detectar tópicos y analizar sentimientos con costo operativo cero y total privacidad.

## Tecnologías Utilizadas
* **[n8n](https://n8n.io/):** Orquestador de la automatización (Logic Engine).
* **[Ollama](https://ollama.com/):** Servidor de IA local para ejecutar modelos como Llama 3 o Mistral.
* **[YouTube Data API v3](https://developers.google.com/youtube/v3):** Extracción de metadatos de la plataforma.

## Características
* 🔍 **Búsqueda Automatizada:** Filtra videos tendencia basados en palabras clave.
* 🤖 **Procesamiento con Ollama:** Utiliza modelos de código abierto para resúmenes y análisis.
* 🎭 **Análisis de Sentimiento:** Clasifica la percepción de la audiencia de forma privada.
